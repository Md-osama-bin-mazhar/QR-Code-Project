# QR-Code-Project
This is a simple QR Code Generator built using HTML, CSS, and JavaScript. The application allows users to enter a text or URL, generate a QR code, and display it dynamically.🚀 Features 🔹 Enter text or a URL to generate a QR code 🔹 Responsive and user-friendly design 🔹 Uses api.qrserver.com to generate QR codes 🔹  Lightweight and easy to use
